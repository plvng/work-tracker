# Work Tracker

Минималистичное Android-приложение для учёта рабочего времени и стоимости работы.

## Возможности

- Большая круглая кнопка **Начать / Стоп**
- Название задачи (tap для смены)
- Повторное имя задачи суммирует часы
- **Комментарий к задаче** — один на задачу, редактируется в сводке отчёта
- Экран **Отчёт**: сводка + хронология
- **Экспорт PDF** в `Downloads/WorkTracker/` — красивый отчёт для начальника
- Настраиваемая ставка ₽/ч (по умолчанию 1000)
- Кнопки навигации **внизу экрана** (удобно для телефонов с челкой, например Huawei P40 Pro)

## Сборка APK

```bash
cd work-tracker
./scripts/build-apk.sh
```

APK:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

## Установка

1. Скопируйте `app-debug.apk` на Android
2. Откройте файл → **Установить**
3. При обновлении с v1.0 данные сессий **сохраняются** (миграция БД)

## Использование

1. Tap по названию задачи → введите имя → **Сохранить**
2. **Начать** / **Стоп** — учёт времени
3. Внизу: **Отчёт** и **Настройки**
4. В сводке отчёта — tap «Добавить комментарий» у задачи
5. В отчёте внизу: **Экспорт PDF** → snackbar **Открыть**
